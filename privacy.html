Политика конфиденциальности

  1. Общие положения

    Настоящая политика конфиденциальности определяет порядок обработки и защиты персональных данных пользователей сайта https://www.hc-capital.ru/ (далее — Сайт). Оператором персональных данных является: Производственный кооператив «Семейные ценности» (ПК «Семейные ценности»), действующий в соответствии с законодательством Российской Федерации. Сайт https://www.hc-capital.ru/ является отдельным интернет-ресурсом, представляющим направление деятельности ПК «Семейные ценности». Использование Сайта означает согласие пользователя с настоящей Политикой конфиденциальности и условиями обработки его персональных данных.

  2. Персональные данные пользователей

    Оператор может обрабатывать следующие персональные данные:

    • Имя
    • Номер телефона
    • Адрес электронной почты (email)
    • Иные данные, предоставленные пользователем добровольно через формы на сайте

  3. Цели обработки персональных данных

    Персональные данные пользователей обрабатываются в следующих целях:

    • Обработка входящих заявок
    • Связь с пользователем (консультация, уточнение информации)
    • Предоставление услуг
    • Направление коммерческих предложений
    • Улучшение качества работы сайта

  4. . Правовые основания обработки

    Оператор обрабатывает персональные данные пользователей на основании:

    • Федерального закона РФ №152-ФЗ «О персональных данных»
    • Согласия пользователя на обработку персональных данных

  5. . Порядок обработки и хранения данных

    Обработка персональных данных осуществляется с соблюдением принципов:

    • Законности и справедливости
    • Ограничения обработки конкретными целями
    • Недопущения избыточности данных

    Персональные данные хранятся не дольше, чем это требуется для целей обработки. Оператор принимает все необходимые организационные и технические меры для защиты персональных данных от:

    • неправомерного доступа
    • изменения
    • раскрытия
    • уничтожения

  6. Передача персональных данных третьим лицам

    Персональные данные могут передаваться третьим лицам только в следующих случаях:

    • если это необходимо для оказания услуг
    • если передача предусмотрена законодательством РФ
    • с согласия пользователя

  7. Использование файлов cookie

    Сайт может использовать файлы cookie для:

    • корректной работы сайта
    • анализа поведения пользователей
    • улучшения пользовательского опыта

    Пользователь может отключить cookie в настройках браузера.

    Пользователь имеет право:

    • Получать информацию о своих персональных данных
    • Требовать их уточнения, блокировки или удаления

    Для реализации своих прав пользователь может направить запрос на электронную почту Оператора.
