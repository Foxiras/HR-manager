# Рабочая версия сайта

Рабочая папка — Hr_test. Основной HR-manager пока не изменён.

Публичные файлы: index.html, privacy.html, consent.html, .htaccess и папки styles, images, fonts, api.

В _deploy находятся серверные исходники, SQL и инструкция. Их можно хранить в основном Git-репозитории, но папку _deploy НЕ загружать в публичную папку www/hc-capital.ru. Её private размещается вне www по инструкции. Реальные config.php и пароли не должны попадать в Git.

Форма по умолчанию выключена. При открытии index.html двойным кликом PHP и база не работают. Приём заявок проверяется через HTTPS на настроенном хостинге.

Инструкция _deploy/УСТАНОВКА.md рассчитана на архив сборки: public/ соответствует публичным файлам в корне Hr_test, а private/ и database/ находятся внутри _deploy/.

Текущий основной репозиторий запускает GitHub Pages при push в main. До публикации нужно согласовать переключение. DNS и CNAME не изменялись.
